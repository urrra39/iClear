# Known side effects of pausing, and what iClear does about them

A paused app keeps its memory and state but runs no code until it resumes. Some effects
follow from that and cannot be removed; iClear limits when they can happen. Measurements:
[VALIDATION.md](VALIDATION.md) (1.0 lab, "Side effects") and the v1.2 rows below; criteria:
[RELEASE_CRITERIA_v1.2.md](RELEASE_CRITERIA_v1.2.md).

| Side effect | Cause | What iClear does | What you can do | Measured |
|---|---|---|---|---|
| Network and WebSocket drops | A paused app cannot answer heartbeats; servers time the connection out. iClear cannot answer for it. | Chat, mail, calendar and media apps are never paused by default; nothing is paused with active connections, while it plays audio, uses the microphone or camera, or downloads. Static wake windows (opt-in rule pack) resume a chat app briefly on a schedule. | Leave chat apps protected, or opt in with a wake window. | 1.0 lab: a heartbeat client reconnected about 1.1 s after resume and lost no message; a client without a heartbeat stayed offline after pauses of 60 s or more; wake windows cut the worst delay from 296 s to 36 s. Adaptive wake windows (v1.2 S1): **not run**, they stay off. |
| Time skew, short sessions | The clock keeps running while an app is paused: a short session or token expires on the server whether or not the app runs. iClear cannot change that. | Password managers, VPN and sign-in apps form the SESSION class and are never paused by default. Each class has a maximum pause (browsers 120 min, chat and players 60 min if you opted them in, others 240 min). `iclear compat <app>` shows the risk; the window shows how long each app has been paused. | Lower `maxPauseMinutes` for a class, or deny an app. | 1.0 lab: a repeating timer fires once after resume (no burst); timeouts that span the pause expire at once. The v1.2 expiring-token fixture: **not run**. Class limits and SESSION: unit tests. |
| Apps with visible windows | A paused window stops redrawing. | Visible apps are never paused automatically. Battery Saver (off by default) can lower their priority instead. The window lists visible-but-unused apps with their measured background power and offers "Pause anyway" with a warning; clicking the window resumes the app. | Use "Pause anyway" only for windows you are not watching. | Unit tests. A second display was not available: the multi-display case is **not validated**. |
| Resume latency after swap-out | The signal arrives in well under a millisecond, but memory that macOS compressed or swapped out must be read back; that depends on the disk and the app's footprint and cannot be removed. | The last 3 apps you used within 30 minutes are never paused automatically (MRU protection, configurable). | Keep apps you return to often out of the allow list. | 1.0 lab: responsive again within 15.1 ms at p99 (no induced swap-out). The v1.2 swap-out latency run (1-2 GB fixtures under the memory emulation, on battery): **not run** (the Mac was on AC). Pre-resume stays off. |
| Notifications | A paused app cannot post notifications that its own code would schedule or receive. | No relay is promised. Apps that receive messages over their own connections are protected by default (chat, mail, calendar). | Keep apps whose notifications matter protected. | Local notifications scheduled before a pause and remote push: **not validated** (a fixture needs notification permission that only a person can grant). |
| "Not Responding" in Force Quit or Activity Monitor | That is how a paused app looks to them. | Activation resumes it. | Do not force-quit it; switch to it. | — |
| Extra window after pop on macOS 26 without Accessibility | Releases up to 1.0.3 activated stashed apps through LaunchServices repeatedly; an app without a visible window answers that with a new window. | v1.2: pop asks the running app to activate itself first and uses LaunchServices at most once, only when a window is on screen. | Granting Accessibility avoids that path entirely. | v1.2 test without Accessibility: 30/30 local runs and 22/22 macOS 26 CI runs with no extra window ([QUALITY.md](QUALITY.md)). |
